# Как добавлять материалы на сайт

Эта инструкция рассчитана на человека без опыта программирования.

Главное правило: **не нужно создавать страницы, ссылки, карточки или маршруты вручную**. Вы добавляете обычный Markdown-файл с текстом — статический генератор сам создаёт страницу, навигацию, адрес, метаданные и запись в поиске.

## Где лежат материалы

Все учебные материалы находятся здесь:

```text
content/
└── colleges/
    └── bashlarova/
        ├── college.json
        └── topics/
            ├── 01-bronchitis.md
            ├── 02-pneumonia.md
            └── ...
```

Каждый колледж хранится в отдельной папке. Внутри папки `topics` один файл равен одной учебной теме.

## Как добавить новую тему

1. Откройте папку нужного колледжа, затем `topics`.
2. Скопируйте любой существующий файл `.md`.
3. Переименуйте копию. Например: `09-heart-failure.md`.
4. Измените данные между двумя линиями `---`.
5. Ниже второй линии `---` вставьте учебный текст.
6. Пересоберите сайт командой `npm run build`.

После этого тема автоматически появится в нужном курсе, предмете, разделе, поиске и sitemap. Готовые HTML-файлы будут находиться в папке `dist/`.

## Поля в начале файла

```yaml
---
collegeSlug: bashlarova
course: 3
subject: Терапия
subjectSlug: therapy
section: Пульмонология
sectionSlug: pulmonology
order: 9
slug: heart-failure
title: Сердечная недостаточность
description: Краткое описание темы для поиска и поисковых систем.
keywords: ["сердце", "отеки", "одышка"]
---
```

| Поле | Что писать |
| --- | --- |
| `collegeSlug` | Короткое техническое имя колледжа. Для текущего колледжа — `bashlarova`. |
| `course` | Номер курса: `1`, `2`, `3` или `4`. |
| `subject` | Название предмета для студентов, например `Терапия`. |
| `subjectSlug` | Короткое имя предмета латиницей, например `therapy`. |
| `section` | Название раздела, если он нужен. |
| `sectionSlug` | Короткое имя раздела латиницей. |
| `order` | Порядок темы внутри раздела или предмета: `1`, `2`, `3` и так далее. |
| `slug` | Последняя часть адреса страницы латиницей, без пробелов. |
| `title` | Полное название темы. |
| `description` | Одно короткое предложение о содержании темы. |
| `keywords` | Дополнительные слова для поиска в квадратных скобках и кавычках. |

### Если раздел не нужен

Просто удалите строки `section` и `sectionSlug`.

Пример:

```yaml
---
collegeSlug: bashlarova
course: 3
subject: Фармакология
subjectSlug: pharmacology
order: 1
slug: antibiotics
title: Антибиотики
description: Основные группы антибиотиков и принципы их применения.
keywords: ["антибактериальные препараты", "резистентность"]
---
```

Тогда сайт построит путь без лишнего раздела:

```text
Колледж → 3 курс → Фармакология → Антибиотики
```

## Как добавить курс

Отдельный файл курса создавать не нужно.

Укажите в новой теме:

```yaml
course: 1
```

Если на первом курсе раньше не было материалов, он автоматически станет доступным на странице колледжа.

## Как добавить предмет

Отдельную страницу предмета создавать не нужно. Укажите в теме новое название и одинаковый `subjectSlug`:

```yaml
subject: Анатомия
subjectSlug: anatomy
```

Все файлы с этими значениями автоматически соберутся в предмет «Анатомия».

Важно: для одного предмета всегда используйте одинаковое написание. Не смешивайте `anatomy` и `anatomiya`.

## Как добавить раздел

Добавьте в тему две строки:

```yaml
section: Кардиология
sectionSlug: cardiology
```

Все темы с такими значениями объединятся в раздел «Кардиология».

Если предмету разделы не нужны, не добавляйте эти поля.

## Как добавить новый колледж

1. В папке `content/colleges` создайте новую папку, например `second-college`.
2. Внутри создайте файл `college.json`.
3. Создайте рядом папку `topics`.

Пример `college.json`:

```json
{
  "slug": "second-college",
  "name": "Полное название учебного заведения",
  "shortName": "Короткое название",
  "description": "Короткое описание материалов этого колледжа."
}
```

В `college.json` можно также указать подпись направления, которая показывается мелко над выбором курсов и **не создаёт отдельный уровень навигации**:

```json
"program": "Лечебное дело"
```

В темах этого колледжа используйте:

```yaml
collegeSlug: second-college
```

Материалы разных колледжей не смешиваются.

## Как писать текст

Обычный текст пишется обычными абзацами. Между абзацами оставляйте пустую строку.

```markdown
Пневмония — острое инфекционное заболевание.

Следующий абзац начинается после пустой строки.
```

## Заголовки

```markdown
## Большой раздел

### Подраздел

#### Небольшой заголовок
```

Заголовки второго и третьего уровней автоматически попадут в содержание страницы.

Не используйте `#` внутри текста темы: главный заголовок сайт создаёт из поля `title`.

## Списки

Маркированный список:

```markdown
- кашель;
- одышка;
- боль в грудной клетке.
```

Нумерованный список:

```markdown
1. Сбор жалоб.
2. Осмотр.
3. Лабораторная диагностика.
```

## Выделение важного

Жирный текст:

```markdown
**Важно запомнить:** далее идёт ключевая мысль.
```

Спокойная заметка:

```markdown
> [!NOTE]
> Дополнительное пояснение для студента.
```

Важное клиническое замечание:

```markdown
> [!IMPORTANT]
> Кровохарканье требует особого внимания.
```

Не превращайте каждый абзац в такой блок. Используйте его только для действительно важной информации.

## Таблицы

```markdown
| Признак | Лёгкая степень | Тяжёлая степень |
| --- | --- | --- |
| Температура | До 38 °C | Выше 39 °C |
| Частота дыхания | До 25/мин | Более 30/мин |
```

На телефоне широкая таблица прокручивается внутри своего блока и не растягивает всю страницу.

## Изображения

1. Положите изображение в папку `public/images/topics`.
2. Используйте понятное имя латиницей, например `lung-segments.webp`.
3. В нужном месте темы добавьте:

```markdown
![Сегменты лёгких](/images/topics/lung-segments.webp)
```

Лучше использовать WebP, AVIF, JPEG или PNG. Перед добавлением уменьшите очень большие файлы. Для большинства схем достаточно ширины 1200–1600 пикселей.

Текст в квадратных скобках должен коротко объяснять, что изображено.

## Как изменить порядок тем

Измените число:

```yaml
order: 4
```

Темы с меньшим числом будут выше. Чтобы позже вставлять материалы между существующими темами, можно использовать шаг 10: `10`, `20`, `30`.

Число в названии файла помогает ориентироваться в папке, но реальный порядок на сайте задаёт поле `order`.

## Как перенести тему

Чтобы перенести тему:

- в другой предмет — измените `subject` и `subjectSlug`;
- в другой раздел — измените или удалите `section` и `sectionSlug`;
- на другой курс — измените `course`;
- в другой колледж — перенесите файл в папку нового колледжа и измените `collegeSlug`.

Старый адрес после переноса изменится. Если страница уже была опубликована и проиндексирована, желательно отдельно настроить перенаправление со старого адреса.

## Проверка перед публикацией

Перед сборкой проверьте:

- `collegeSlug`, `subjectSlug`, `sectionSlug` и `slug` написаны латиницей без пробелов;
- поля `course` и `order` содержат числа;
- у темы есть `title` и `description`;
- в таблицах одинаковое количество столбцов;
- путь к изображению начинается с `/images/topics/`.

Если обязательное поле пропущено или два файла создают один и тот же адрес, сборка остановится и покажет, какой файл нужно исправить.


## Что происходит при сборке

Команда:

```bash
npm run build
```

читает все Markdown-файлы и заново создаёт папку `dist/`. Сервер для опубликованного сайта не нужен. Поиск выполняется в браузере, а прогресс чтения хранится в `localStorage` отдельно для каждой темы.
